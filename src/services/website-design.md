explainer:
  heading: Structure first, then the words, then the design.
  paragraphs:
    - Most sites are organised the way the company is organised internally, which is almost never how a stranger reads. Structure means deciding which single page carries the weight, what one thing you want somebody to do, and what order of information earns enough trust for them to do it. That gets settled before anything is drawn.
    - Copy comes next, still before design. Words written to fill a finished layout end up saying whatever fits the box. Design made to carry words that already exist ends up saying something. It is the same amount of work in a different order, and the order is the whole difference.
    - Then the parts nobody sees. A CMS so you can change a price yourself. Forms wired into whatever system you already follow up in, so an enquiry lands somewhere alive rather than in an inbox. Analytics set up properly so you can tell what happened. Accessibility measured against a standard rather than assumed.
  glossary:
    - term: Sitemap
      definition: The list of every page and how they relate, agreed before any design starts.
    - term: Wireframe
      definition: A layout with no styling, used to settle structure without arguing about colour.
    - term: CMS
      definition: The admin area that lets you edit text, images and prices without a developer.
    - term: CRM
      definition: Where an enquiry lands and gets followed up, rather than sitting in an inbox.
    - term: Landing page
      definition: A single page built for one campaign and one action, with no navigation to wander off into.
    - term: WCAG 2.2 AA
      definition: The accessibility standard a site should be measured against, not guessed at.

faq:
  - q: What does a website build cost?
    a: It depends on page count and what has to be wired in. There is one fixed price agreed before anything starts, and it stays fixed because the spec removes the guesswork. No prices are posted here because quoting a range that fits nobody helps nobody.
  - q: Can I edit the site myself afterwards?
    a: Yes. Every build ships on a CMS with a handover walkthrough. Text, images, prices and listings are yours to change without calling anyone.
  - q: Do you write the copy?
    a: Yes, and before the design rather than after it. Copy written to fit a layout is how sites end up saying nothing in particular.
